# 綴り談話室 v1 利用マニュアル

**Ollama + VOICEVOX に対応したローカル AI チャットアプリ**

[最新版を GitHub Releases からダウンロード](https://github.com/AglaoDev-jp/tsuzuri-danwashitsu/releases/tag/v1.0.0)

本アプリは、ローカル環境で動作する LLM（大規模言語モデル）と会話できる GUI チャットアプリです。  
`profiles.json` に登録されたキャラクターや用途別プロンプトを切り替えながら、AI との会話を楽しめます。

> [!NOTE]
> 本マニュアルは、アプリのソースコードおよび仕様をもとに、OpenAI の対話型 AI「ChatGPT」の支援を受けて草案を作成し、作者が内容の確認・編集を行っています。

## 主な機能

- Ollama を利用したローカル AI チャット
- AI 応答のストリーミング表示
- キャラクターや用途別プロンプトの切り替え
- Ollama にインストールされているモデル一覧の自動取得・更新
- Thinking モードの切り替え（対応モデルのみ）
- ユーザーが誤入力できない表示専用のチャット欄
- AI 返答中の設定変更・クリア・保存をロックし、会話履歴の混線を防止
- `profiles.json` の読込失敗時に、原因を警告して臨時プロフィールで起動
- キャラクターごとのアバター切り替え
- AI アバター表示／非表示の切り替えと設定保存
- AI の待機状態と返答内容に応じた表情切り替え
- VOICEVOX による AI 応答の順次読み上げ
- VOICEVOX の話者 ID 指定
- 読み上げの途中停止
- チャットログの保存
- 一時音声ファイルの自動管理

## 必要なもの

### 必須

- Windows PC
- Ollama
- Ollama に対応したダウンロード済みのモデル

### 音声読み上げを使用する場合

- VOICEVOX
- 音声を再生できる環境

実行ファイル版では、Python、`requests`、`pygame` を別途インストールする必要はありません。  
Ollama と使用モデルは、実行ファイルには含まれていません。VOICEVOX も別途用意してください。

## セットアップ

### 1. 配布 ZIP を展開する

1. [GitHub Releases](https://github.com/AglaoDev-jp/suitto-talk/releases) から配布 ZIP をダウンロードします。
2. ZIP を右クリックし、「すべて展開」を選びます。
3. 展開後の `綴り談話室` フォルダを任意の場所へ置きます。

> [!IMPORTANT]
> ZIP 内から直接起動しないでください。  
> `綴り談話室.exe` だけを別の場所へ移動せず、配布フォルダの構成を保ってください。

### 2. Ollama をインストールする

- [Ollama 公式サイト](https://ollama.com/)

Ollama をインストールしたあと、使用するモデルをダウンロードします。

例：

```bash
ollama pull gemma4:e2b
```

上記以外の Ollama 対応モデルも利用できます。

モデルによって、必要なメモリ容量、応答速度、日本語性能、Thinking モードへの対応状況が異なります。  
動作が重い場合は、より軽量なモデルをお試しください。

### 3. Ollama を起動する

通常は、Ollama を起動した状態で本アプリを使用します。  
Ollama に接続できない場合は、コマンドプロンプトから次を実行してください。

```bash
ollama serve
```

Ollama API は通常、次のアドレスで動作します。

```text
http://localhost:11434
```

### 4. VOICEVOX をインストールする（任意）

音声読み上げを使用する場合は、VOICEVOX をインストールしてください。

- [VOICEVOX 公式サイト](https://voicevox.hiroshiba.jp/)
- [VOICEVOX GitHub](https://github.com/VOICEVOX/voicevox)

読み上げを使用するときは、VOICEVOX を起動した状態で本アプリを利用してください。  
VOICEVOX ENGINE は通常、次のアドレスで動作します。

```text
http://127.0.0.1:50021
```

VOICEVOX を使用しない場合でも、Ollama によるチャット機能は利用できます。

1. Ollama を起動します。
2. 音声読み上げを使用する場合は、VOICEVOX も起動します。
3. 配布フォルダ内の `綴り談話室.exe` をダブルクリックします。

正常に起動すると、「綴り談話室」のウィンドウが表示されます。

Windows の保護画面が表示された場合は、ダウンロード元が本プロジェクトの GitHub Releases であることを確認し、内容を理解したうえで実行するか判断してください。

ソースコードからの起動方法や PyInstaller によるビルド方法は、GitHub リポジトリの [README.md](https://github.com/AglaoDev-jp/suitto-talk#readme) に記載しています。

## 画面の見方

### 1. キャラ

`profiles.json` に登録されているキャラクターや用途別プロンプトを選択します。

キャラを変更すると、AI に渡している会話履歴はリセットされ、新しい設定で会話を開始します。  
チャット画面に表示済みの文章は残るため、表示も消したい場合は「クリア」を押してください。

### 2. モデル

Ollama にインストールされているモデルから、会話に使用するモデルを選択します。

モデルを変更しても、現在の会話履歴は引き継がれます。  
別のモデルで新しい会話を始めたい場合は、モデル変更後に「クリア」を押してください。

### 3. モデル更新

Ollama にインストールされているモデル一覧を再取得します。

次のような場合に使用してください。

- アプリ起動後に Ollama を起動した
- 新しいモデルをダウンロードした
- モデルを削除した
- 起動時にモデル一覧を取得できなかった

### 4. Thinking

Thinking モードの ON／OFF を切り替えます。

- チェックあり: `think: true`
- チェックなし: `think: false`

本アプリでは、モデルの内部思考内容は表示せず、通常の回答本文のみを表示します。

### 5. VOICEVOX 読み上げ

チェックを入れると、AI の応答を VOICEVOX で読み上げます。初期状態では ON です。

VOICEVOX を使用しない場合は、送信前にチェックを外してください。  
VOICEVOX が起動していない場合は警告を表示し、音声なしでチャットを続けます。

### 6. 話者 ID

VOICEVOX で使用する話者 ID を半角数字で入力します。初期値は `3` です。

別の声を使用する場合は、使用したい VOICEVOX キャラクター・スタイルの話者 ID を指定してください。  
数字以外を入力した場合、その送信では読み上げを行わず、チャットのみ続行します。

### 7. 読み上げ停止

現在再生中の音声と、生成・再生待ちの音声を停止します。  
停止後も、AI の回答本文は引き続き生成・表示されます。

### 8. AIアバターを表示する

チェックありでは右側にAIアバターを表示し、チェックなしではアバター枠そのものを収納します。  
OFFにするとチャット表示欄が空いた横幅を使用します。この設定は終了時にも保存され、次回起動時に引き継がれます。

### 9. AI アバター

Ollama の返答待ちには `thinking`、返答後は内容に応じた表情を表示します。

アバターは VOICEVOX のキャラクターとは連動しません。  
キャラを変更すると、`profiles.json` の `avatar_id` に対応する画像フォルダへ切り替わります。  
表情画像が不足している場合は、そのキャラクターの `normal.png`、共通のdefault画像、内蔵の仮表示の順で切り替わり、チャットは継続します。

### 10. チャット表示欄

ユーザーの入力、AI の回答、使用モデル、Thinking の状態、各種メッセージが表示されます。

```text
[Model: 使用モデル名 / Thinking: ON または OFF]
あなた: 入力内容
AI: AIの回答
```

### 11. 入力欄

AI に送りたい文章を入力します。

### 12. 送信

入力した文章を AI に送信します。Enter キーでも送信できます。

AI の回答中は、会話履歴の混線を防ぐため、送信・入力・キャラ・モデル・モデル更新・Thinking・VOICEVOX 設定・クリア・保存が一時的に無効になります。  
読み上げ中の「読み上げ停止」は、そのまま使用できます。  
回答が終了すると、自動的に再び入力できる状態になります。

### 13. クリア

チャット表示欄と、AI に渡している会話履歴をリセットします。  
現在選択されているキャラ設定は維持されます。

### 14. 保存

現在チャット画面に表示されている内容を、テキストファイルとして `logs` フォルダへ保存します。

## 基本的な使い方

### 通常のチャット

1. Ollama を起動します。
2. 本アプリを起動します。
3. 「モデル」から使用するモデルを選択します。
4. 「キャラ」から使用する設定を選択します。
5. 必要に応じて Thinking、VOICEVOX、AIアバター表示の設定を変更します。
6. 画面下部の入力欄に文章を入力します。
7. 「送信」または Enter キーで送信します。
8. AI の回答がチャット欄に順次表示されます。

### 音声読み上げを使用する場合

1. Ollama と VOICEVOX の両方を起動します。
2. 「VOICEVOX 読み上げ」にチェックを入れます。
3. 使用する話者 ID を入力します。
4. 文章を送信します。
5. AI の回答が一定の長さに分割され、生成中から順次読み上げられます。
6. 途中で止めたい場合は、「読み上げ停止」を押します。

## モデル選択と Thinking モード

### 起動時のモデル一覧取得

本アプリは起動時に、Ollama の `/api/tags` からモデル一覧を取得します。  
取得に成功すると、インストール済みのモデルが「モデル」欄に表示されます。

### 初期選択されるモデル

- `gemma4:e2b` がインストールされている場合は、初期モデルとして選択されます。
- 見つからない場合は、取得できたモデル一覧の先頭が選択されます。

### モデル一覧を取得できなかった場合

Ollama が起動していない場合や通信に失敗した場合は、次の予備モデル一覧が表示されます。

- `gemma4:e2b`
- `gemma4`
- `qwen3`
- `llama3.2`

> [!WARNING]
> 予備モデル一覧は画面に表示する候補であり、実際にインストールされていることを保証するものではありません。

Ollama を起動したあとに「モデル更新」を押してください。

### Thinking モードの注意

モデルや Ollama のバージョンによっては、次のような場合があります。

- Thinking に対応していない
- ON／OFF の違いが明確に現れない
- ON にすると応答開始まで時間がかかる
- モデルによって出力品質や速度が大きく変わる

Thinking が不要な場合や、軽快に会話したい場合は OFF をお試しください。

## VOICEVOX 読み上げ

### 読み上げの仕組み

AI の回答をすべて受信してから再生するのではなく、回答生成中の文章を適度な長さに分割して、順次 VOICEVOX へ送信します。

1. Ollama から回答の一部を受信
2. 読み上げやすい長さに文章を分割
3. VOICEVOX で WAV 音声を生成
4. 生成済み音声を順番に再生
5. 再生済みの一時 WAV ファイルを削除

### 読み上げ用テキストの調整

VOICEVOX へ送る文章では、読み上げを自然にするため、Markdown 記号、絵文字、一部の特殊記号、空白、改行などを簡易的に調整します。  
チャット画面に表示する AI の回答本文は変更されません。

### 一時音声ファイル

生成した音声は `voice_cache` フォルダへ一時的に保存されます。  
再生済みの音声は自動的に削除され、起動時、読み上げ停止時、終了時にもキャッシュを整理します。

### 設定を変更するタイミング

VOICEVOX の ON／OFF と話者 ID は、メッセージを送信した時点の設定が使われます。  
回答の途中で止める場合は、チェックを外すのではなく「読み上げ停止」を使用してください。

## チャットのクリアと保存

### クリア

「クリア」を押すと、次の内容をリセットします。

- チャット画面に表示されている内容
- ユーザーと AI の会話履歴

現在選択中のキャラ設定は維持されます。

### 保存

「保存」を押すと、その時点でチャット画面に表示されている内容を `logs` フォルダへ保存します。

ファイル名の形式：

```text
chat_log_YYYYMMDD_HHMMSS_キャラクター名_モデル名.txt
```

モデル名に含まれる `:` と `/` は、ファイル名では `_` に置き換えられます。

## キャラクターの追加・編集

キャラクターや用途別プロンプトは、配布フォルダ内の `profiles.json` に JSON 形式で記述します。

例：

```json
{
  "優しいAI": {
    "prompt": "あなたは丁寧で優しいアシスタントです。",
    "avatar_id": "kind"
  },
  "文章校正": {
    "prompt": "あなたは日本語文章の校正担当者です。誤字脱字と不自然な表現を確認し、修正案を提示してください。",
    "avatar_id": "proofreader"
  }
}
```

各項目の意味は次のとおりです。

- `prompt`: AIへ設定するキャラクター・用途別プロンプト
- `avatar_id`: `assets/avatars/` の直下に作る画像フォルダ名

旧バージョンのように、右側へプロンプト文字列だけを書いた形式も読み込めます。その場合のアバターは共通defaultになります。

### 本番用アバター画像の追加

たとえば `avatar_id` が `kind` のキャラクターなら、通常画像を次の場所へ保存します。

```text
assets/avatars/kind/normal.png
```

表情差分を加える場合は、同じ `kind` フォルダへ次の名前で保存します。

```text
normal.png
smile.png
sad.png
angry.png
surprised.png
troubled.png
thinking.png
```

`happy.png` と `serious.png` も使用できます。すべてを用意する必要はありません。  
選択された表情画像がない場合は `kind/normal.png`、共通の `default` フォルダ、内蔵表示の順で安全に補われます。

### 編集手順

1. 綴り談話室を終了します。
2. `profiles.json` のバックアップを作成します。
3. `profiles.json` をテキストエディターで開きます。
4. JSON の書式を保って内容を追加・編集します。
5. UTF-8 形式で保存します。
6. 綴り談話室を再起動します。

### JSON 編集時の注意

- 項目と項目の間にはカンマが必要です。
- 最後の項目の後ろには、通常カンマを付けません。
- 文字列は半角のダブルクォーテーション `"` で囲みます。
- JSON 内にコメントは記述できません。
- 同じ名前を重複させないでください。

書式が崩れると、アプリが起動できなくなる場合があります。  
起動時には、`profiles.json` の先頭にある設定が初期選択されます。

## 配布フォルダの内容

主なファイルとフォルダは次のとおりです。`profiles.json` と `assets` はexeの隣に置きます。
`_internal` は実行に必要な内部ファイル用です。削除せず、exeと一緒に保管してください。

```text
綴り談話室/
├─ 綴り談話室.exe
├─ README_PLAY.md
├─ profiles.json
├─ _internal/  # Pythonランタイム・DLLなど（削除しない）
├─ assets/
│  └─ avatars/
│     └─ default/
│        ├─ normal.png
│        ├─ smile.png
│        ├─ happy.png
│        ├─ thinking.png
│        ├─ surprised.png
│        ├─ sad.png
│        └─ serious.png
└─ licenses/
   ├─ application/
   └─ third_party/
```

実行後、exeのあるフォルダに次のファイル・フォルダが必要に応じて自動作成されます。

- `logs`: 保存したチャットログ
- `voice_cache`: VOICEVOX の一時音声ファイル
- `user_settings.json`: AIアバターの表示／非表示設定

配布版には、利用者向けの本ファイル `README_PLAY.md` を同梱しています。  
ソースコード、ビルド方法、開発情報は、GitHub リポジトリの `README.md` をご確認ください。

## トラブルシューティング

### Ollama に接続できない

表示例：

```text
--- Ollamaに接続できませんでした。Ollamaが起動しているか確認してください。---
```

確認事項：

1. Ollama がインストールされているか
2. Ollama が起動しているか
3. `ollama serve` が実行できるか
4. 使用するモデルがダウンロード済みか
5. `http://localhost:11434` を別の設定へ変更していないか

### モデル一覧に実際のモデルが表示されない

1. Ollama を起動します。
2. 「モデル更新」を押します。
3. インストール済みモデルが表示されるか確認します。

インストール済みモデルは、次のコマンドでも確認できます。

```bash
ollama list
```

### AI の応答が遅い、またはタイムアウトする

- より軽量なモデルへ変更する
- Thinking を OFF にする
- 他の負荷が高いアプリを終了する
- 長すぎる入力を短くする
- Ollama を再起動する

### VOICEVOX に接続できない

1. VOICEVOX がインストールされているか確認します。
2. VOICEVOX を起動します。
3. 「VOICEVOX 読み上げ」にチェックが入っているか確認します。
4. `http://127.0.0.1:50021` を変更していないか確認します。

VOICEVOX に接続できなくても、チャット機能は利用できます。

### 話者 ID のエラーが表示される

「話者 ID」欄に半角数字を入力してください。

### 音声が再生されない

- VOICEVOX が起動しているか
- 話者 ID が正しいか
- PC がミュートになっていないか
- 音声出力先が正しいか
- 別のアプリが音声デバイスを占有していないか

### 読み上げ開始まで時間がかかる

VOICEVOX の初回処理、話者、文章の長さ、PC の性能によって時間がかかる場合があります。  
短い文章で試し、VOICEVOX 単体で音声を生成できるか確認してください。

### `profiles.json` の読み込み警告が表示される

`profiles.json` が見つからない、JSON の書式が壊れている、内容が空などの場合でも、アプリは強制終了せず、臨時の「標準AI」で起動します。  
警告画面には、書式エラーの行・文字位置など、確認できた原因が表示されます。

- JSON のカンマ、ダブルクォーテーション、波括弧を確認する
- プロフィール名が空になっていないか確認する
- 各プロフィールが `prompt` と `avatar_id` を持つオブジェクトになっているか確認する
- `prompt` の値が文字列になっているか確認する
- 文字コードを UTF-8 にする
- 必要に応じて編集前のバックアップへ戻す

`prompt` の空文字列 `""` は、「追加のキャラクター設定なし」で会話する標準モードとして利用できます。  
`avatar_id` がない・不正・対応フォルダがない場合も、共通default画像へ切り替えて会話を継続します。

アプリは問題のある `profiles.json` を自動で上書きしません。  
修正後に綴り談話室を再起動すると、通常のプロフィールを読み込みます。

### チャットログが見つからない

配布フォルダ内の `logs` フォルダを確認してください。  
ZIP 内から直接起動した場合や、`綴り談話室.exe` だけを移動した場合は、正しく保存できない可能性があります。

## 既知の制限事項

- Thinking モードの対応状況は、使用するモデルと Ollama のバージョンによって異なります。
- PC の性能や使用モデルによって、AI の応答速度が大きく異なります。
- 初回の音声生成や長文読み上げでは、再生開始まで時間がかかる場合があります。
- 読み上げ停止後も、VOICEVOX ENGINE へ送信済みの処理が一時的に継続する場合があります。
- Ollama または VOICEVOX のポート番号を変更している場合は、ソースコード側の設定変更が必要です。
- ローカル LLM が感情形式を守らない場合は、表情を `neutral` にして本文を優先します。
- アバターの口パクとまばたきには対応していません。
