# すいっとトーク（suitto-talk）v2 利用マニュアル
> [!NOTE]
> 本マニュアルは、アプリのソースコードおよび仕様をもとに、OpenAIの対話型AI「ChatGPT」が草案を作成し、作者が内容の確認・編集を行っています。

**Ollama + VOICEVOX に対応したローカル AI チャットアプリ**

本アプリは、ローカル環境で動作する LLM（大規模言語モデル）と会話できる、シンプルな GUI チャットアプリです。  
`profiles.json` に登録されたキャラクターを切り替えながら、AI との会話を楽しめます。

v2 では、Ollama のモデル一覧取得、Thinking モード、VOICEVOX による音声読み上げなどに対応しました。

## 主な機能

- Ollama を利用したローカル AI チャット
- AI 応答のストリーミング表示
- キャラクター（AI 人格）の切り替え
- Ollama にインストールされているモデル一覧の自動取得
- GUI からのモデル一覧更新
- Thinking モードの切り替え（対応モデルのみ）
- VOICEVOX による AI 応答の順次読み上げ
- VOICEVOX の話者 ID 指定
- 読み上げの途中停止
- チャットログの保存
- 一時音声ファイルの自動管理

---

## 動作環境

### 必須

- Python 3.8 以上
- Ollama
- Ollama に対応したダウンロード済みのモデル
- `profiles.json`

### 音声読み上げを使用する場合

- VOICEVOX
- 音声再生が可能な環境

### Python 外部ライブラリ

- `requests`
- `pygame`

`tkinter` は通常、Python に同梱されています。

## セットアップ

### 1. Ollama をインストールする

Ollama 公式サイトからインストールしてください。

https://ollama.com/

---

### 2. 使用するモデルをダウンロードする

本アプリでは、Ollama にインストールされているモデルを自動取得し、画面上で選択できます。

モデルのダウンロード例：

```bash
ollama pull gemma4:e2b
```

```bash
ollama pull qwen3
```

```bash
ollama pull llama3.2
```

上記以外の Ollama 対応モデルも利用できます。

> [!NOTE]
> モデルによって、必要なメモリ容量、応答速度、日本語性能、Thinking モードへの対応状況が異なります。  
> 動作が重い場合は、より軽量なモデルをお試しください。

---

### 3. Ollama を起動する

通常は、Ollama を起動した状態で本アプリを使用します。

Ollama に接続できない場合は、ターミナルやコマンドプロンプトから次のコマンドを実行してください。

```bash
ollama serve
```

Ollama API は、通常、次のアドレスで動作します。

```text
http://localhost:11434
```

---

### 4. VOICEVOX をインストールする（任意）

音声読み上げを使用する場合は、VOICEVOX をインストールしてください。

- VOICEVOX 公式サイト  
  https://voicevox.hiroshiba.jp/

- VOICEVOX GitHub  
  https://github.com/VOICEVOX/voicevox

本アプリには、VOICEVOX 本体は含まれていません。  
読み上げを使用するときは、VOICEVOX を起動した状態で本アプリを利用してください。

VOICEVOX ENGINE は、通常、次のアドレスで動作します。

```text
http://127.0.0.1:50021
```

---

### 5. Python ライブラリをインストールする

ターミナルまたはコマンドプロンプトで、次のコマンドを実行してください。

```bash
pip install requests pygame
```

環境によっては、次の形式で実行します。

```bash
python -m pip install requests pygame
```

Windows の Python Launcher を使用している場合：

```bash
py -m pip install requests pygame
```

---

### 6. 必要なファイルを配置する

少なくとも、次のファイルを同じフォルダに配置してください。

```text
suitto-talk/
├─ main_script_v2.py
└─ profiles.json
```

`profiles.json` が存在しない場合や、JSON の書式が正しくない場合は、アプリを正常に起動できません。

## 起動方法

スクリプトのあるフォルダで、次のコマンドを実行します。

```bash
python main_script_v2.py
```

Windows の Python Launcher を使用する場合：

```bash
py main_script_v2.py
```

正常に起動すると、「すいっとトーク（suitto-talk）」のウィンドウが表示されます。

## 画面の見方

### 1. キャラ

`profiles.json` に登録されているキャラクターを選択します。

キャラクターを変更すると、AI に渡している会話履歴はリセットされ、新しいキャラクター設定で会話を開始します。

> [!NOTE]
> キャラクターを変更しても、チャット画面に表示済みの文章は消えません。  
> 表示も消したい場合は、「クリア」ボタンを押してください。

---

### 2. モデル

Ollama にインストールされているモデルから、会話に使用するモデルを選択します。

モデルを変更しても、現在の会話履歴はそのまま引き継がれます。  
別のモデルで新しい会話を始めたい場合は、モデル変更後に「クリア」ボタンを押してください。

---

### 3. モデル更新

Ollama にインストールされているモデル一覧を再取得します。

次のような場合に使用してください。

- アプリ起動後に Ollama を起動した
- 新しいモデルをダウンロードした
- モデルを削除した
- 起動時にモデル一覧を取得できなかった

---

### 4. Thinking

Thinking モードの ON／OFF を切り替えます。

- チェックあり：`think: true`
- チェックなし：`think: false`

対応モデルでは、回答前の推論処理が有効になる場合があります。

本アプリでは、モデルの内部思考内容は表示せず、通常の回答本文のみを表示します。

---

### 5. VOICEVOX 読み上げ

チェックを入れると、AI の応答を VOICEVOX で読み上げます。

初期状態では、読み上げが ON になっています。

VOICEVOX を使用しない場合は、送信前にチェックを外してください。  
VOICEVOX が起動していない状態でチェックが入っている場合は、警告を表示したうえで、音声なしのチャットを続行します。

---

### 6. 話者 ID

VOICEVOX で使用する話者 ID を数字で入力します。

初期値は次のとおりです。

```text
3
```

別の声を使用する場合は、使用したい VOICEVOX キャラクター・スタイルの話者 ID を入力してください。

> [!IMPORTANT]
> 話者 ID には数字を入力してください。  
> 数字以外を入力した場合、その送信では読み上げを行わず、チャットのみ続行します。

---

### 7. 読み上げ停止

現在再生中の音声と、生成・再生待ちの音声を停止します。

停止後も、AI の回答本文は引き続き生成・表示されます。

VOICEVOX ENGINE にすでに送信された通信処理は、すぐには終了しない場合がありますが、停止後に生成された音声は再生されません。

---

### 8. チャット表示欄

ユーザーの入力、AI の回答、使用モデル、Thinking の状態、各種メッセージが表示されます。

送信時には、次のような情報が表示されます。

```text
[Model: 使用モデル名 / Thinking: ON または OFF]
あなた: 入力内容
AI: AIの回答
```

---

### 9. 入力欄

AI に送りたい文章を入力します。

---

### 10. 送信

入力した文章を AI に送信します。

Enter キーでも送信できます。

AI の回答中は、連続送信による混線を防ぐため、送信ボタンと入力欄が一時的に無効になります。  
回答が終了すると、自動的に再び入力できる状態になります。

---

### 11. クリア

チャット表示欄と、AI に渡している会話履歴をリセットします。

現在選択されているキャラクター設定は維持されます。

---

### 12. 保存

現在チャット画面に表示されている内容を、テキストファイルとして保存します。

保存先は、スクリプトと同じ場所に自動作成される `logs` フォルダです。

---

## 基本的な使い方

### 通常のチャット

1. Ollama を起動します。
2. 使用するモデルがインストールされていることを確認します。
3. 本アプリを起動します。
4. 「モデル」から使用するモデルを選択します。
5. 「キャラ」から使用するキャラクターを選択します。
6. 必要に応じて Thinking と VOICEVOX の設定を変更します。
7. 画面下部の入力欄に文章を入力します。
8. 「送信」ボタンまたは Enter キーで送信します。
9. AI の回答がチャット欄に順次表示されます。

---

### 音声読み上げを使用する場合

1. Ollama と VOICEVOX の両方を起動します。
2. 本アプリを起動します。
3. 「VOICEVOX 読み上げ」にチェックを入れます。
4. 使用する話者 ID を数字で入力します。
5. 文章を送信します。
6. AI の回答が一定の長さに分割され、生成中から順次読み上げられます。
7. 途中で止めたい場合は、「読み上げ停止」を押します。

---

### 音声読み上げを使用しない場合

「VOICEVOX 読み上げ」のチェックを外してから送信してください。

VOICEVOX をインストールしていなくても、Ollama によるチャット機能のみ使用できます。

## モデル選択

### 起動時のモデル一覧取得

本アプリは起動時に、Ollama の次の API からモデル一覧を取得します。

```text
http://localhost:11434/api/tags
```

取得に成功すると、Ollama にインストールされているモデルが「モデル」欄に表示されます。

---

### 初期選択されるモデル

`gemma4:e2b` がインストールされている場合は、初期モデルとして選択されます。

`gemma4:e2b` が見つからない場合は、取得できたモデル一覧の先頭が選択されます。

---

### モデル一覧を取得できなかった場合

Ollama が起動していない場合や、通信に失敗した場合は、次の予備モデル一覧が表示されます。

- `gemma4:e2b`
- `gemma4`
- `qwen3`
- `llama3.2`

> [!WARNING]
> 予備モデル一覧は、取得失敗時に画面へ表示する候補です。  
> それぞれのモデルが実際にインストールされていることを保証するものではありません。

Ollama を起動したあとに「モデル更新」を押し、実際にインストールされているモデル一覧を再取得してください。

---

## Thinking モード

Thinking のチェック状態は、メッセージを送信した時点で Ollama API に渡されます。

モデルや Ollama のバージョンによっては、次のような場合があります。

- Thinking に対応していない
- ON／OFF の違いが明確に現れない
- Thinking を ON にすると応答開始まで時間がかかる
- モデルによって出力品質や速度が変化する

Thinking が不要な場合や、軽快に会話したい場合は OFF をお試しください。

---

## キャラクター変更

キャラクター設定は、`profiles.json` から読み込まれます。

キャラクターを変更すると、次の処理が行われます。

- それまでの AI 用会話履歴をリセット
- 新しいキャラクターの system プロンプトを設定
- 共通の安全ガイドラインを再設定

チャット画面の過去の表示は残ります。

完全に画面を整理して新しい会話を始める場合は、キャラクター変更後に「クリア」を押してください。

## VOICEVOX 読み上げ

### 読み上げの仕組み

AI の回答をすべて受信してから再生するのではなく、回答生成中の文章を適度な長さに分割して、順次 VOICEVOX に送信します。

処理は、おおむね次の順番で行われます。

1. Ollama から回答の一部を受信
2. 読み上げやすい長さに文章を分割
3. VOICEVOX で WAV 音声を生成
4. 生成済み音声を順番に再生
5. 再生済みの一時 WAV ファイルを削除

このため、AI の回答全文が完成する前から読み上げを開始できます。

---

### 読み上げ用テキストの調整

VOICEVOX へ送る文章では、読み上げを自然にするため、次のような簡易整形を行います。

- Markdown 記号の一部を削除
- 箇条書き記号の一部を削除
- 絵文字や一部の特殊記号を削除
- 空白と改行を整理
- 長い文章を複数の短い文章へ分割

チャット画面に表示する AI の回答本文は変更されません。

---

### 一時音声ファイル

生成された音声は、`voice_cache` フォルダへ一時的に保存されます。

再生済みの音声は自動的に削除されます。  
また、次のタイミングでもキャッシュの削除を行います。

- アプリ起動時
- 読み上げ停止時
- アプリ終了時

`voice_cache` 内のファイルは一時データのため、通常は利用者が操作する必要はありません。

---

### 読み上げ設定を変更するタイミング

VOICEVOX の ON／OFF と話者 ID は、メッセージを送信するときの設定が使用されます。

回答の途中で読み上げを止める場合は、チェックを外すのではなく「読み上げ停止」を使用してください。

次のメッセージから読み上げを使わない場合は、「VOICEVOX 読み上げ」のチェックを外してから送信します。

---

## チャットのクリアと保存

### クリア

「クリア」を押すと、次の内容がリセットされます。

- チャット画面に表示されている内容
- ユーザーと AI の会話履歴

現在選択中のキャラクター設定は維持されます。

---

### 保存

「保存」を押すと、現在チャット画面に表示されている内容を保存します。

保存先：

```text
logs/
```

ファイル名の形式：

```text
chat_log_YYYYMMDD_HHMMSS_キャラクター名_モデル名.txt
```

例：

```text
chat_log_20260715_153000_優しいAI_gemma4_e2b.txt
```

モデル名に含まれる `:` と `/` は、ファイル名では `_` に置き換えられます。

> [!NOTE]
> 保存されるのは、保存ボタンを押した時点でチャット画面に表示されている内容です。

## キャラクターの追加・編集

キャラクターは、`profiles.json` に JSON 形式で記述します。

例：

```json
{
  "優しいAI": "あなたは丁寧で優しいアシスタントです。",
  "クールAI": "あなたは落ち着いた口調で簡潔に回答するアシスタントです。"
}
```

左側が、画面の「キャラ」欄に表示される名前です。  
右側が、そのキャラクターへ設定されるプロンプトです。

### ベースプロンプトとして利用する

`profiles.json` に登録する内容は、必ずしも架空のキャラクターや人格設定である必要はありません。

普段よく使用する指示や、作業目的に合わせたAIの役割を登録しておくことで、用途別のベースプロンプトとして利用できます。

使用例：

* 文章の誤字脱字や表現を確認する校正用プロンプト
* Pythonを段階的に教える学習サポート用プロンプト
* アイデアを整理し、複数の案を提示する企画支援用プロンプト
* 長い文章の要点をまとめる要約用プロンプト
* 丁寧なメール文章を作成するビジネス文章用プロンプト

例：

```json
{
  "優しいAI": "あなたは丁寧で優しいアシスタントです。",
  "文章校正": "あなたは日本語文章の校正担当者です。誤字脱字、不自然な表現、分かりにくい箇所を確認し、修正案を提示してください。",
  "Python学習": "あなたはPythonの学習を支援する先生です。初心者にも理解できるように、具体例とコメント付きコードを使って段階的に説明してください。",
  "アイデア整理": "あなたは企画支援アシスタントです。ユーザーの考えを整理し、長所、課題、改善案、次に検討する事項を提示してください。"
}
```

左側の名前は、アプリ画面の「キャラ」欄に表示されます。
キャラクター名に限らず、「文章校正」「Python学習」など、用途が分かる名前を付けることができます。

選択した項目のプロンプトは、その後の会話における基本的な応答方針として使用されます。

> [!NOTE]
> 別のキャラクターまたはベースプロンプトへ変更すると、AIに渡している会話履歴はリセットされます。
> チャット画面に表示済みの文章は残るため、画面も整理したい場合は「クリア」ボタンを押してください。

---

### キャラクターを追加する手順

1. アプリを終了します。
2. `profiles.json` をテキストエディターで開きます。
3. JSON の書式を保ったまま、新しいキャラクターを追加します。
4. UTF-8 形式で保存します。
5. アプリを再起動します。

---

### JSON 編集時の注意

- 項目と項目の間にはカンマが必要です。
- 最後の項目の後ろには、通常カンマを付けません。
- 文字列はダブルクォーテーション `"` で囲みます。
- 全角の引用符は使用しないでください。
- JSON 内にコメントは記述できません。
- 同じキャラクター名を重複させないでください。

書式が崩れると、アプリが起動できなくなる場合があります。  
編集前に `profiles.json` のバックアップを作成することをおすすめします。

---

### 起動時に選択されるキャラクター

`profiles.json` の先頭に記述されているキャラクターが、起動時の初期キャラクターになります。

## フォルダとファイル

構成例：

```text
suitto-talk/

├─ logs/
│  └─ chat_log_*.txt
```

### `main_script_v2.py`

アプリ本体の Python スクリプトです。

保存したチャットログが格納されます。

### `voice_cache`

VOICEVOX で生成した一時 WAV ファイルが格納されます。  
フォルダが存在しない場合は、自動作成されます。

## トラブルシューティング

### Ollama に接続できない

表示例：

```text
--- Ollamaに接続できませんでした。Ollamaが起動しているか確認してください。---
```

確認事項：

1. Ollama がインストールされているか
2. Ollama が起動しているか
3. `ollama serve` が実行できるか
4. 使用するモデルがダウンロード済みか
5. `http://localhost:11434` を別の設定へ変更していないか

---

### モデル一覧に実際のモデルが表示されない

起動時に Ollama へ接続できなかった可能性があります。

1. Ollama を起動します。
2. アプリ画面の「モデル更新」を押します。
3. インストール済みモデルが表示されるか確認します。

予備モデルが表示されていても、そのモデルがインストール済みとは限りません。

---

### モデルが見つからない・実行できない

ターミナルで、インストール済みモデルを確認します。

```bash
ollama list
```

必要なモデルがない場合は、ダウンロードします。

```bash
ollama pull モデル名
```

---

### AI の応答が遅い、またはタイムアウトする

表示例：

```text
--- 応答がタイムアウトしました。モデルが重い場合は、もう少し軽いモデルを試してください。---
```

対処例：

- より軽量なモデルへ変更する
- Thinking を OFF にする
- 他の負荷が高いアプリを終了する
- 長すぎる入力を短くする
- Ollama を再起動する

---

### VOICEVOX に接続できない

表示例：

```text
--- VOICEVOXに接続できませんでした。VOICEVOXを起動してください。---
```

確認事項：

1. VOICEVOX がインストールされているか
2. VOICEVOX が起動しているか
3. 「VOICEVOX 読み上げ」にチェックが入っているか
4. `http://127.0.0.1:50021` を別の設定へ変更していないか

VOICEVOX に接続できなくても、チャット機能はそのまま利用できます。

---

### 話者 ID のエラーが表示される

表示例：

```text
--- 話者IDは数字で入力してください。読み上げはOFF扱いで続行します。---
```

「話者 ID」欄に半角数字を入力してください。

例：

```text
3
```

---

### 音声が再生されない

確認事項：

- 「VOICEVOX 読み上げ」にチェックが入っているか
- VOICEVOX が起動しているか
- 話者 ID が正しいか
- PC がミュートになっていないか
- 音声出力先が正しいか
- `pygame` がインストールされているか
- 別のアプリが音声デバイスを占有していないか

---

### 読み上げ開始まで時間がかかる

初回の音声生成、長い文章、PC の処理性能、使用する話者などの影響で、再生開始まで時間がかかる場合があります。

AI の回答表示が進んでいても、音声生成が追いつくまで待ち時間が発生することがあります。

---

### 読み上げを停止しても処理が残っているように見える

停止ボタンを押すと、再生中の音声と待機中の音声は停止されます。

ただし、VOICEVOX ENGINE にすでに送信済みの HTTP リクエストは、即座に中断できない場合があります。  
停止後に返ってきた音声は、再生されないように処理されます。

---

### `profiles.json` のエラーで起動できない

確認事項：

- `profiles.json` がスクリプトと同じフォルダにあるか
- JSON のカンマが不足していないか
- 余分なカンマがないか
- キーと値がダブルクォーテーションで囲まれているか
- ファイルが UTF-8 で保存されているか

---

### チャットログが見つからない

チャットログは、スクリプトと同じフォルダ内の `logs` に保存されます。

空のチャット欄は保存できません。

```text

http://127.0.0.1:50021/audio_query
```

音声合成：

```text
http://127.0.0.1:50021/synthesis
```

---

### ストリーミング応答

Ollama API へ `stream: true` を送信し、AI の回答を少しずつ受信してチャット欄へ表示します。

---

### 会話履歴

ユーザーと AI の会話は、Ollama API へ送る `messages` に保持されます。

会話履歴がリセットされる操作：

- キャラクター変更
- 「クリア」ボタン

モデル変更だけでは、会話履歴はリセットされません。

---

### 共通安全ガイドライン

各キャラクターのプロンプトには、アプリ共通の安全ガイドラインが追加されます。

キャラクター変更時やチャットのクリア時にも、共通ガイドラインは再設定されます。

## 既知の制限事項

- Thinking モードの対応状況は、使用するモデルと Ollama のバージョンによって異なります。
- 非対応モデルでは、Thinking の切り替えが期待どおりに反映されない場合があります。
- PC の性能や使用モデルによって、AI の応答速度が大きく異なります。
- 初回の音声生成や長文読み上げでは、再生開始まで時間がかかる場合があります。
- VOICEVOX の話者や文章によって、音声生成が安定しない場合があります。
- 読み上げ停止後も、送信済みの通信処理が一時的に継続する場合があります。
- Ollama または VOICEVOX のポート番号を変更している場合は、スクリプト側の設定変更が必要です。
- 本アプリはローカル環境での利用を想定しています。
