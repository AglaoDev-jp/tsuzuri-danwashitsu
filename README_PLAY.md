# すいっとトーク（suitto-talk）のつかいかた

**Ollamaを使用した軽量GUIチャットアプリ**

本アプリは、ローカル環境で動作するLLM（大規模言語モデル）を利用した、シンプルなチャットアプリです。
キャラクター（人格）を切り替えながら会話を楽しむことができます。

---

## 🧩 概要

* ローカルLLM（Ollama）を利用したチャットアプリ
* キャラクター（AI人格）の切り替え機能
* チャット履歴の保存機能
* シンプルなGUI（Tkinter）

---

## ⚙️ 動作環境

* Python 3.10 以上
* Ollama（ローカルLLM実行環境）

---

## 🚀 セットアップ

### 1. Ollamaのインストール

以下の公式サイトからインストールしてください：

https://ollama.com/

---

### 2. モデルのダウンロード

本アプリでは以下のモデルを使用しています：

```
gemma3:1b
```

コマンド：

```bash
ollama pull gemma3:1b
```

---

### 3. Ollamaの起動

```bash
ollama serve
```

※ デフォルトで `http://localhost:11434` にAPIが立ち上がります

---

### 4. 必要ライブラリのインストール

```bash
pip install requests
```

（Tkinterは通常Pythonに同梱されています）

---

## ▶️ 起動方法

```bash
python main.py
```

---

## 💬 使い方

### ■ 基本操作

1. テキストボックスに入力
2. 「送信」ボタン or Enterキーで送信
3. AIからの応答が表示される

---

### ■ キャラクター変更

画面上部の「キャラ選択」から変更できます。

* キャラごとに人格（プロンプト）が設定されています
* 変更すると会話履歴はリセットされます

---

### ■ チャットクリア

「クリア」ボタンで会話履歴を削除します

---

### ■ チャット保存

「保存」ボタンでログを保存できます

保存先：

```
logs/chat_log_日時_キャラ名.txt
```

---

## 🧠 技術的な仕組み

### ■ Ollama API

本アプリは以下のAPIにリクエストを送信しています：

```
http://localhost:11434/api/chat
```

これは：

* `localhost` → 自分のPC
* `11434` → Ollamaのデフォルトポート

---

### ■ ストリーミング応答

AIの応答はストリーミング形式で受信し、リアルタイム表示しています。

---

### ■ キャラクター管理

```
profiles.json
```

に定義された内容を読み込み、以下として使用：

* systemロール（AIの性格・口調）

---

## ⚠️ 注意事項

* Ollamaが起動していない場合、通信エラーになります
* モデルが未ダウンロードの場合は動作しません
* ローカル環境でのみ動作します（クラウドではありません）

---

## 🔧 カスタマイズ

### ■ キャラクター追加

`profiles.json` に追加するだけでOKです

例：

```json
{
  "優しいAI": "あなたは丁寧で優しいアシスタントです。",
  "クールAI": "あなたは無口でクールな性格です。"
}
```
